📌 Project Overview
This project predicts whether a customer has a Good or Bad Credit Risk using a Machine Learning model. A Streamlit web application is used to provide an interactive interface where users can enter customer details and receive a credit risk prediction.

🚀 Features
Predicts customer credit risk
Interactive Streamlit web application
User-friendly interface
Displays customer input details
Fast and easy prediction

🛠️ Technologies Used
Python
Pandas
NumPy
Scikit-learn
Streamlit
Pickle

📂 Project Files
app.py – Streamlit application
credit_risk_model.pkl – Trained machine learning model
requirements.txt – Project dependencies

▶️ How to Run
Install the required libraries:
pip install -r requirements.txt
Run the application:
streamlit run app.py

📊 Output
The application predicts whether the customer is a Good Credit Risk or a Bad Credit Risk based on the entered details.
